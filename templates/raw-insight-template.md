## Source references

When this note points to another source, add its stable ID. Keep `path` as a
human-friendly hint only:

```yaml
source_refs:
  - source_id: src_<lowercase-uuidv4>
    path: 6-raw/inbox/example.md
    relationship: supports
```

`source` is retained for older capture metadata such as `customer` or `ceo`.
It does not identify the file. New captures use `source_id` for the captured
file and `source_refs` for referenced material.
